# 次回Codexへの推奨プロンプト

```text
GitHub完全習得プロジェクトを引き継いでください。
README、AGENTS、plans/STATUS、audits/audit-report、research/research-gaps、
RESEARCH_PROTOCOLを読み、現在のremote・branch・差分と保存済み成果を確認してください。

基準日は2026-10-26のまま、実際の追加確認日を別に記録してください。
現行Docsの記述だけで基準日時点の仕様を断定しないでください。

今回は第1・2・5・6・9章のFeature IDを抽出し、公式詳細資料、プラン、権限、
提供状態、UI導線の不足を解消してください。利用可能な許可済み環境だけで実画面を
確認し、使えない画面は条件と検証手順を残してください。
Phase 3としてPRレビューとCI/CDの企業公開事例を各1件調査し、公開日・主張・根拠・
適用限界をcase-studiesの形式で記録してください。
台帳統合・内部リンク・MkDocs strict buildを実行し、監査と進捗を更新してください。

全50章本文は生成しないでください。対象章の執筆前ゲートを解消した後、
次の制作候補は第1章としてください。

成果は専用ブランチへ途中保存してください。環境消失で未push成果が失われた経緯があります。
main初期化pushは過去の自動承認レビューで拒否されました。明示承認なく再試行せず、
mainへのマージ、公開設定変更、有料契約、Pages公開も行わないでください。
完了時は調査範囲、作成資料、検証、未確認、保存先commit/PRを報告してください。
```
